# Employee Management System

## About the Project

Employee Management System is a web-based application developed using ASP.NET.

The main purpose of this project is to manage employee information in an organized way. It helps to add, view, update, and manage employee details easily.

## Features

- Employee Login
- Add Employee Details
- View Employee Details
- Update Employee Information
- Employee List
- Leave Management
- Department Management
- Simple and User-Friendly Interface

## Technologies Used

- ASP.NET
- C#
- HTML
- CSS
- SQL Server
- Visual Studio

## Project Modules

### Employee Management
This module is used to add and manage employee information.

### Employee List
This module displays the list of employees and their details.

### Department Management
This module is used to manage department-related information.

### Leave Management
This module helps to manage employee leave details.

### Login
The login module provides access to the system for authorized users.

## Purpose

The project is developed to make employee information management easier, faster, and more organized.
